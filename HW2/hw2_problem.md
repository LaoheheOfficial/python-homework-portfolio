# Parking Garage Fee Calculator

Write a Python program that calculates how much a customer needs to pay for parking.

The program should:

1. Ask the user how many hours they parked.
2. Ask whether it is a weekday or weekend.
3. Check that the number of hours is greater than 0 and no more than 24.
4. Calculate the parking cost using these rules:
   - First 2 hours: $5
   - More than 2 hours but no more than 6 hours: $10
   - More than 6 hours: $15
5. If it is a weekend, give the customer a 20% discount.
6. Write at least one function to calculate the parking cost.
7. Print the final cost in a clear sentence with two decimal places.

## Explanation

This problem is meant to practice functions, conditional statements, Boolean logic, input validation, and formatted output. I chose these skills because I sometimes find it difficult to organize several conditions and decide which code should run in each situation.

I think the most challenging part is making sure the conditions are in the correct order and applying the weekend discount after finding the normal parking price. By completing this problem, a student can practice breaking a larger problem into smaller steps and using if, elif, and else correctly.
